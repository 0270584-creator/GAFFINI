# Gaffini — Website

Static site (HTML / CSS / JS, no build step).

## Preview locally
Double-click **Preview Gaffini.command** (keep the Terminal window open while browsing).
Or simply double-click `index.html` — the site works without a server.

## Where to edit
- `js/products.js` — products, prices, colours, currency
- `index.html` — page copy and sections
- `css/styles.css` — colours & fonts (top of file, `:root`)
- `assets/img/` — put photos here

Large videos (*.mov, *.mp4) are ignored by git (GitHub rejects files over 100 MB).
